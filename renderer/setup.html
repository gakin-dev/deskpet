DeskPet 시작하기

펫이 대화하고 일할 때 쓸 AI를 하나 골라주세요. 이 컴퓨터에 로그인된 구독으로 돌아요 (API 키 필요 없음).

Claude Code

Anthropic. 평소 쓰던 Claude Code에 그대로 연결해요 (스킬·플러그인·MCP·권한 설정 그대로). 설정에 없는 권한은 말풍선으로 물어봐요.

Codex

OpenAI. 평소 쓰던 Codex에 그대로 연결해요 (ChatGPT 계정). 실행 중엔 하나하나 물어볼 수 없어서 아래 권한 안에서 일해요.

항상 허용한 동작 말풍선에서 [항상 허용]을 누른 것들이에요. 펫에게만 적용되고, 평소 Claude Code 권한 설정은 안 바뀌어요.
    나중에 캐릭터 우클릭 → "AI 설정"에서 바꿀 수 있어요

    DeskPet은 따로 AI를 갖고 있지 않아요. 이 컴퓨터에 설치·로그인된 Claude Code나 Codex에 그대로 연결해서, 캐릭터 성격만 덧붙여 써요. 그래서 평소 쓰던 스킬, 플러그인, MCP, 권한 설정이 그대로 따라오고, API 키 없이 내 구독(Claude 구독 / ChatGPT 계정)으로 돌아요. 내 컴퓨터에서 나만 쓰는 용도예요.

    대화도 일도 한 세션에서

    • 입력창 여는 법: 캐릭터를 누르거나, 어느 앱에서든 ⌥ Option + ⇧ Shift + Space를 누르세요. 한 번 더 누르면 닫혀요. (config.json의 chat_hotkey로 바꿀 수 있어요)
    • 그냥 말하면 돼요: "안녕"이든 "다운로드 폴더 정리해줘"든 같은 입력창에 말하면, AI가 대화면 대답하고 일이면 도구를 써서 직접 해요.
    • 캐릭터 성격: 스튜디오에서 정한 성격, 말투, 감정별 대사, 평상시 기분 비율, 규칙(rules.md)을 Claude Code 기본 프롬프트 뒤에 덧붙여요. 원래 능력은 그대로고 말투만 캐릭터가 돼요.
    • 규칙과 스킬: 캐릭터마다 스튜디오 "규칙" 탭에서 항상 따를 규칙을, "스킬" 탭에서 필요할 때만 쓰는 스킬(Claude Code 스킬)을 만들 수 있어요. 스킬은 그 캐릭터에만 적용돼요.
    • 감정 태그: AI는 대답 앞에 [happy] 같은 태그를 붙이고, 펫은 그걸로 표정·움직임을 골라요. 정해진 대사 캐릭터(의성어로만 말하는 캐릭터 등)는 평소엔 그 감정의 소리로 말하고, 일을 한 대답이나 물어본 것에 대한 정보 대답(자기소개, 사용법 등)만 글자로 보여줘요.
    • 진행 상황: 일하는 동안 말풍선 아래에 "💻 명령", "✏️ 파일 고치는 중", "🧩 스킬" 같은 한 줄이 떠요. 우클릭 → "하던 일 멈추기"로 멈출 수 있어요.

    기억

    • 대화 기억 = 그 AI 세션의 대화 내역이에요. 캐릭터마다 세션 id를 저장해둬서(~/.deskpet/characters/<캐릭터>/session.json) 앱을 껐다 켜도 이어서 말해요.
    • 대화 정리: 말할 때마다 지난 대화가 같이 들어가서, 쌓일수록 한 번 말하는 데 드는 양이 커져요. 그래서 대화가 3만 토큰쯤 쌓이면 펫이 조용할 때 알아서 요약 정리(/compact)해요. 나에 대해 알게 된 것, 하던 일, 관계는 요약으로 남아요.
    • 캐릭터를 바꾸면 그 캐릭터의 세션으로 바뀌어요. 캐릭터마다 기억이 따로예요.
    • 잊고 새로 시작하려면 우클릭 → "○○와(과) 대화 새로 시작".
    • Claude Code를 고르면 펫이 켜질 때 그 세션을 미리 띄워두고 말만 주고받아요 (대답 1~3초). 30분 조용하면 닫았다가 다음 말에 다시 이어서 열어요.
    • Codex를 고르면 말할 때마다 codex를 켜서 캐릭터의 대화방에 이어 말해요. Codex는 0.1초 안에 켜져서 켜두지 않아도 느려지지 않아요.
    • 펫 전용 폴더: 펫의 Claude Code 세션은 ~/Desktop-pet/<캐릭터> 폴더에서 돌아요. 캐릭터마다 기억·스킬이 따로예요. 그래서 펫이 "기억해줘"로 저장한 기억과 대화 목록이 평소 Claude Code 작업과 섞이지 않아요. 파일은 작업 폴더(기본: 홈 전체)를 열어줘서 평소처럼 다룰 수 있어요.
    • 펫을 끈 상태에서 터미널로 cd ~/Desktop-pet/<캐릭터> && claude --resume 하면 펫과 나눈 대화를 Claude Code 화면으로 열어볼 수 있어요. (펫이 켜져 있을 때 같이 쓰면 대화가 꼬일 수 있어요)

    권한

    • Claude Code: 평소 Claude Code 권한 설정(~/.claude/settings.json)을 그대로 따라요. 이미 허용해둔 건 그냥 하고, 그 밖의 것(명령 실행, 파일 수정 등)은 말풍선으로 물어봐요. [해줘 / 하지 마 / 항상 허용 / 이번 일은 다 맡길게]
    • 항상 허용: 누르면 그 동작(같은 명령, 같은 사이트, 같은 파일, 같은 도구)은 다음부터 안 물어봐요. 펫에게만 적용되고, 설정 탭 아래 "항상 허용한 동작"에서 보고 지울 수 있어요.
    • Codex: 실행 중엔 하나하나 물어볼 수 없어서, AI 설정에서 고른 권한(읽기만 / 작업 폴더 안에서 고치기) 안에서만 일해요.
    • 작업 폴더: 기본은 홈 폴더예요. 우클릭 → 작업 폴더에서 바꿀 수 있어요. 바꿔도 대화 기억은 그대로예요.
    • 상황 반응(잔소리 등)에선 도구를 못 쓰게 막아둬요. 펫이 혼자 일을 벌이지 않아요.

    AI를 쓰는 때 / 안 쓰는 때

    AI를 써요 (사용량 듦)AI 없이 해요
    내가 말을 걸 때 / 일을 시킬 때처음 인사 · 딴짓 잔소리 · 휴식 권유 · 먼저 말 걸기 (스튜디오 반응 탭에 써둔 대사)
    스튜디오 대화 테스트, 연결 테스트앱을 바꿀 때 한마디 · 자리 비움 · 돌아옴
    반응 탭에서 "AI로 말하기"를 켠 반응만평상시 기분 바꾸기 · 돌아다니기 · 감정 미리보기 · 오늘 요약

    펫이 혼자 하는 반응은 기본으로 AI를 안 써요. 내 Claude Code를 그대로 쓰는 만큼 한 번 부를 때 수만 토큰이 들어서예요. 화면이 잠겨 있거나 자리를 비우면 아무 반응도 안 해요. 세션이 떠 있기만 할 땐 사용량을 안 써요.

    AI에게 보내는 정보

    • 지금 쓰는 앱 이름, 앱별 사용 시간, 지금 시각, 내가 입력한 말, 최근 대화.
    • 윈도우에선 브라우저 창 제목에서 걸린 키워드만(예: youtube) 보내고, 창 제목 전체는 안 보내요.
    • 화면 내용, 키보드 입력은 보내지 않아요. 파일은 일을 부탁했을 때 AI가 직접 읽는 것만 가요.

    기록 보기

    • 대화 창: 우클릭 → "대화 창 열기" (또는 긴 말풍선의 "전체 보기"). 최근 대화를 보고 여기서도 말을 걸 수 있어요. 위쪽에 오늘 AI를 몇 번, 얼마나 썼는지 나와요.
    • 대화 기록: 우클릭 → "대화 기록 보기 (터미널)". 펫이 AI에게 보낸 말과 AI의 원래 대답(감정 태그 포함)이 실시간으로 보여요. 파일: ~/.deskpet/chat-log.txt
    • 작업 기록: 우클릭 → "작업 기록 보기". 도구를 써서 한 일만 모아요: 부탁, 승인한 동작, 결과. 파일: ~/.deskpet/agent-log.md

    문제가 생기면

    증상해결
    "못 찾았어"Claude Code나 Codex가 설치돼 있는지 확인. 그래도 안 되면 ~/.deskpet/config.json에 claude_path / codex_path로 위치를 적어주세요.
    "로그인이 풀렸어" / 연결 테스트 실패설정 탭의 [로그인하기] → 터미널에서 로그인 → [연결 테스트]. Codex는 로그인이 풀려도 "준비됨"으로 보일 수 있어서 연결 테스트가 정확해요.
    대답이 느려요AI 설정에서 Claude Code 모델을 Haiku로 바꾸면 가장 빨라요 (대신 일은 약해요). 30분 쉬고 첫 말은 세션을 다시 여느라 조금 더 걸려요.
    예전 일을 기억 못 해요캐릭터를 바꾸면 기억도 따로예요. "대화 새로 시작"을 눌렀다면 그 전 기억은 없어요.
    엉뚱한 감정을 골라요스튜디오 → 감정 표현에서 감정별 대사 예시와 평상시 기분 비율을 고치고, 대화 테스트로 확인해보세요.
