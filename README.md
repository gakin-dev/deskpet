# DeskPet

화면 구석에 사는 데스크톱 펫이에요. 지금 쓰는 앱을 보고 캐릭터 성격대로 반응하고, 말을 걸면 대답하고, 부탁하면 컴퓨터에서 일도 해요.

펫의 머리는 **내 컴퓨터에 설치된 Claude Code 또는 Codex**예요. API 키 없이 각자 로그인한 계정으로 돌고, 평소 쓰던 스킬·설정도 그대로 써요.

## 준비물

- [Node.js](https://nodejs.org) 22 이상
- 아래 중 하나 (설치하고 로그인까지)
  - [Claude Code](https://docs.claude.com/en/docs/claude-code/overview): 터미널에서 `claude` 실행 → 로그인
  - [Codex](https://github.com/openai/codex): 터미널에서 `codex login`

## 설치 · 실행

```bash
git clone https://github.com/<아이디>/deskpet.git
cd deskpet
npm install
npm start
```

`npm start`로 켜면 그 터미널을 닫을 때 펫도 꺼져요. 계속 쓰려면 앱으로 만들어두세요 (아래 "앱으로 만들기").

처음 켜면 **AI 설정 창**이 떠요. Claude Code와 Codex 중 하나를 고르고 [연결 테스트]로 확인한 뒤 [시작하기]를 누르세요.

## 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 말 걸기 · 일 시키기 | 캐릭터 클릭, 또는 어느 앱에서든 `⌥ Option + ⇧ Shift + Space` |
| 옮기기 | 캐릭터 드래그 |
| 메뉴 | 캐릭터 우클릭 |
| 캐릭터 꾸미기 | 우클릭 → 캐릭터 스튜디오 열기 |
| 대화 다시 보기 | 우클릭 → 대화 창 열기 |
| 종료 | 우클릭 → 잘 있어~ (종료) |

- **일 시키기:** "다운로드 폴더 정리해줘"처럼 그냥 말하면 돼요. 명령 실행이나 파일 수정처럼 허락이 필요한 일은 말풍선으로 물어봐요: [해줘 / 하지 마 / 항상 허용 / 이번 일은 다 맡길게]
- **기억:** 캐릭터마다 대화를 기억하고, 껐다 켜도 이어져요. 잊게 하려면 우클릭 → "대화 새로 시작".
- **자기소개:** "너 뭐 할 수 있어?", "단축키 뭐야?"처럼 물어보면 캐릭터가 자기 설정을 보고 알려줘요.
- **자세한 설명:** 우클릭 → AI 사용 가이드

## 캐릭터 스튜디오

우클릭 → **캐릭터 스튜디오 열기**에서 캐릭터를 만들고 꾸며요. 바꾸면 바로 저장되고 펫에 반영돼요.

- **기본:** 이름, 크기, 이미지 (여러 장 넣으면 애니메이션)
- **의사소통:** 자유롭게 말하기 / 정해진 대사만, 말투, 성격
- **감정 표현:** 감정 8가지마다 이미지·움직임·효과·대사, 평상시 기분 비율
- **행동:** 화면 돌아다니기 (범위, 속도, 모서리에서 구경, 가장자리에서 빼꼼)
- **반응:** 인사·잔소리·휴식 권유·먼저 말 걸기 대사와 간격
- **규칙:** 캐릭터가 항상 따르는 규칙 (`rules.md`)
- **스킬:** 그 캐릭터만 쓰는 Claude Code 스킬 (`SKILL.md`)

오른쪽 미리보기에서 바로 보고, 대화 테스트로 말을 걸어볼 수 있어요.

### 캐릭터 주고받기
- **내보내기:** 스튜디오 왼쪽 아래 [내보내기] → `캐릭터이름.deskpet` 파일 하나로 저장돼요. 이름·성격·말투·감정·이미지·반응·규칙·스킬이 들어가고, 나와의 대화 기억은 안 들어가요.
- **가져오기:** 스튜디오 왼쪽 아래 [가져오기] → 받은 `.deskpet` 파일을 고르면 캐릭터가 추가돼요.
- 다른 사람이 그린 캐릭터 이미지는 개인적으로만 주고받아 주세요.

## 앱으로 만들기

```bash
npm run dist
```

`out/` 폴더에 앱이 생겨요 (지금은 맥용 설정만 있어요). 직접 만든 앱이라 처음 열 때 경고가 뜨면 앱을 우클릭 → 열기.

## 내 데이터

| 위치 | 내용 |
|---|---|
| `~/.deskpet/` | 설정, 캐릭터(성격·이미지·규칙), 대화·작업 기록, AI 사용량 |
| `~/Desktop-pet/<캐릭터>/` | 캐릭터의 AI 세션 폴더 (기억, 캐릭터 전용 스킬) |

## 알아둘 것

- 사용량은 각자의 Claude 구독 / ChatGPT 계정에서 빠져요. 펫이 혼자 하는 반응(인사, 잔소리 등)은 기본으로 AI를 안 쓰고, 내가 말을 걸 때만 AI를 써요. 오늘 쓴 양은 우클릭 메뉴와 대화 창 위쪽에 나와요.
- 이 앱은 각자 설치하고 로그인한 Claude Code / Codex를 그대로 불러요. 각 서비스의 이용약관을 따라 개인적으로 사용해주세요.
- AI에게 보내는 건 지금 쓰는 앱 이름, 사용 시간, 시각, 내가 입력한 말이에요. 화면 내용이나 키보드 입력은 보내지 않아요.
- 윈도우에서는 아직 충분히 테스트하지 않았어요.
